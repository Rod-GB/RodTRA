# Gdaw website updates

## 2026-10-29 | Version 1.3.1 — Discount/Price

### Improvements

- Renamed Discounts to Discount/Price.
- Shows paid games at regular and sale prices by default.
- Free-to-play games and giveaways stay in All Games and Genres.
- Use On sale only to narrow the list to paid discounts.

## 2026-10-29 | Version 1.3.0 — Game sets for your budget

### New features

- Budget Finder now picks one set of games within your total budget.
- See how many games were selected, the total price and money left.
- Choose up to three genres and a minimum rating for your set.

### Improvements

- Epic free games stay visible and are grouped by verified genres where available.
- Epic games without a listed genre appear under Other free games.
- itch.io games without a genre are hidden from the catalog.
- Added the Gdaw logo, browser tab icon and desktop cat cursor.

## 2026-10-17 | Version 1.2.1 — Easier browsing

### Improvements

- Shorter labels and cleaner pages on desktop and mobile.
- All listed genres are available in Budget Finder. Pick up to three.
- Epic free games appear directly in Budget Finder.
- Clearer game counts and a simple breakdown by store.

### Fixes

- A failed itch.io game page no longer holds up other game checks.
- itch.io games appear without waiting for comments and developer posts to load.
- Epic games can be sorted by when the free offer ends.
- Removed misleading genre loading messages and unused filters.

## 2026-10-15 | Version 1.2.0 — More stores, prices and game details

### New features

- Browse new itch.io releases and current Epic free games alongside Steam.
- Find games by price, rating and up to three genres. Your choices aren’t saved.
- See original prices, discounts, screenshots, reviews and developer updates where available.
- Browse sales in Discounts.

### Fixes

- Slower sidebar hover effects and better touch feedback.
- Most Played bars show each game’s current players compared with its peak today.
- Clearer game information and links to developer updates.

## 2026-10-12 | Simpler genres and clearer website updates

### Improvements

- The Updates page now shows new features, improvements and fixes for the Gdaw website.
- Choose a genre to see only its games, displayed as game cards.
- Use All genres to return to the genre selection.
- Search, genre filters and sorting are available in All Games.

### Fixes

- Removed game announcements and game filters from the website Updates page.
- Removed the search bar and dropdowns from genre pages.
- Game-specific developer posts are clearly labeled Patch notes inside game details.

## 2026-10-08 | More ways to discover games

### Website features

- All Games has its own library page for searching and browsing the Steam collection.
- Discover games from the dashboard, explore genres or view the Most Played leaderboard.
- Game details include player-history charts, ratings, English reviews and complete developer posts.
- The Gdaw name and shared G icon appear in the browser tab and website header.

### Improvements

- Player counts refresh separately from game details and ratings.
- Available game data and content stay visible during temporary connection problems.
